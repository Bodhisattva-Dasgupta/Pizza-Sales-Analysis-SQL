# Pizza-Sales-Analysis-SQL
Pizza sales analysis project using MySQL

Project Overview:
This project analyses pizza sales data using SQL to understand sales performance, revenue trends, and customer preferences.

Objectives:
Analyse the distribution of pizza types and categories.
Identify the best-selling pizzas.
Calculate total revenue and order-level sales metrics.
Examine sales trends and customer purchasing patterns.

Tools Used:
MySQL

SQL Concepts Used:
SELECT and WHERE
Aggregate functions such as COUNT, SUM and AVG
GROUP BY and ORDER BY
JOIN operations
Subqueries and other advanced SQL concepts, where applicable
